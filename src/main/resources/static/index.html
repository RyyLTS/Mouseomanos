API X-Squad

Back-end do sistema de pedidos da hamburgueria X-Squad (projeto Mouseomanos).

API REST em Spring Boot 4 e Java 17 que gerencia o cardápio e os pedidos. Os dados são trocados em JSON e os valores em reais usam até duas casas decimais.

Clientes

  • Interface web em Angular: Mousseomanos-front
  • App Android nativo: Mousseomanos-android
  • Código desta API: Mouseomanos

Rotas

MétodoRotaDescrição
GET/produtosLista todos os itens cadastrados
GET/produtos/{id}Busca um item
POST/produtosCadastra um item
PUT/produtos/{id}Atualiza um item
PATCH/produtos/{id}/precoAltera o preço: {"valor": 32.90}
PATCH/produtos/{id}/disponibilidadeLiga ou desliga no cardápio: {"disponivel": false}
DELETE/produtos/{id}Exclui um item
GET/cardapioItens disponíveis, por categoria e nome
GET/pedidosPedidos confirmados, do mais recente ao mais antigo
GET/pedidos/{id}Busca um pedido
POST/pedidosConfirma um pedido

Exemplos

Item do cardápio:

{"nome": "X-Bacon", "categoria": "Hambúrgueres", "descricao": "Pão brioche, cheddar e bacon", "valor": 32.90, "disponivel": true}

Pedido (quantidade de 1 a 99 por item; o total é calculado pelo servidor):

{"cliente": "Mesa 4", "observacao": "Sem cebola", "itens": [{"produtoId": 1, "quantidade": 2}]}

Erros

Respostas de erro trazem {"message": "..."}: 400 para dados inválidos, 404 para registro inexistente e 409 quando um item do pedido foi excluído, ficou indisponível ou mudou de preço.
